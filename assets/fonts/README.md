# Diary fonts

Default diary typography is bundled so opening a page needs no font download.

- `Caveat-Medium.ttf`: Caveat, weight 500. SHA-256:
  `bd52370c5ab257b65b726d86455ffe555369e12894f9e36e988542ed070b3a6c`.
- `Lora-Regular.ttf`: Lora, weight 400. SHA-256:
  `e9b4141f57f365b3de9be91123b343311c4c292f063635d38b4bce7f6b19c052`.

These are the unmodified Google Fonts files referenced by the installed
`google_fonts` package. Each was downloaded from
`https://fonts.gstatic.com/s/a/<sha256>.ttf` and its digest verified.

The corresponding SIL Open Font License files are included here, bundled as
assets, and registered with Flutter's license registry. Original license sources:

- https://github.com/google/fonts/blob/main/ofl/caveat/OFL.txt
- https://github.com/google/fonts/blob/main/ofl/lora/OFL.txt
